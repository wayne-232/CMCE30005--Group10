# AI assistance

We used two AI tools. The group is responsible for reviewing AI-assisted code,
results and wording before submission, and for the content submitted.

- **Anthropic Claude** (October 2026) reviewed and extended the R code
  (case selection, size-class, jobs and vacancy analysis, a model diagnostic and
  test fixes), checked results against the source data, and edited the data
  sections of the final report.
- **OpenAI Codex** (August–October 2026) assisted with R code development and
  review, peer comparisons and sensitivity checks, automated tests, charts,
  brainstorming and report editing. The group is responsible for checking these
  outputs before submission.

No source observations were generated or imputed by AI. The supplied raw CSV
files are unchanged. All reported results are calculated from those CLUE files.
